# Journal de bord quotidien — Chef de chantier (Suisse)

Application simple de gestion de tâches pour le suivi quotidien d’un chantier.

Elle permet de créer, modifier, valider et supprimer des tâches, avec sauvegarde automatique dans le navigateur grâce à `localStorage`.

---

## Fonctionnalités

- Ajouter une nouvelle tâche
- Modifier le texte d’une tâche
- Marquer une tâche comme terminée / non terminée
- Supprimer une tâche
- Conserver les tâches après rechargement de la page
- Précharger quelques tâches par défaut lors de la première utilisation

---

## Aperçu

Le journal de bord propose une liste de tâches avec :

- le titre de la tâche
- la date de création
- le statut d’avancement
- des actions rapides (modifier, valider, supprimer)

---

## Technologies utilisées

- HTML
- CSS
- JavaScript
- `localStorage`
